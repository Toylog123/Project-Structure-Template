# 开发经验库（踩坑记录）

> 目的：记录开发中遇到的问题与解决方法，避免反复踩坑。
> **规则：解决任何问题后，在本文件登记——这是记录习惯的一部分。**

## 使用方式

- 新增经验：复制下方模板填入，按类别归入分组。
- 查询经验：按类别浏览，或搜索关键词（现象 / 工具 / 报错片段）。
- 经验增多后：按类别拆分为 `experience/<类别>.md` 并在此登记索引。

## 经验条目模板

### [类别] 一句话问题描述

- **现象**：报错 / 表现（贴关键日志）
- **原因**：根因分析
- **解决**：具体操作 / 命令
- **验证**：如何确认已解决
- **相关**：涉及文件 / 路径 / 工具
- **日期**：YYYY-MM-DD

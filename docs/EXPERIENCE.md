# 开发经验库（踩坑记录）

> 目的：记录开发中遇到的问题与解决方法，避免反复踩坑。
> **规则：解决任何问题后，在本文件登记一条经验——这是记录习惯的一部分。**

## 使用方式

- 新增经验：复制下方"经验条目模板"填入，按类别归入对应分组。
- 查询经验：按类别浏览，或 Ctrl+F 搜索关键词（现象 / 工具 / 报错片段）。
- 经验增多后：按类别拆分为 `experience/<类别>.md` 并在此登记索引。

## 经验条目模板

### [类别] 一句话问题描述

- **现象**：报错 / 表现（贴关键日志）
- **原因**：根因分析
- **解决**：具体操作 / 命令
- **验证**：如何确认已解决
- **相关**：涉及文件 / 路径 / 工具
- **日期**：YYYY-MM-DD

## 经验条目

### Git SSL 证书问题

- **现象**：`git push` 报 `fatal: unable to access ... SSL certificate problem: unable to get local issuer certificate`
- **原因**：Windows 下 git 默认证书后端（openssl）找不到本地 CA 证书
- **解决**：`git config --global http.sslBackend schannel`（改用 Windows 系统证书库）
- **验证**：push 成功，输出 `main -> main`
- **相关**：所有 https 远程仓库推送
- **日期**：2026-08-06

## 规则

1. 问题解决后**当天**登记，不要积累。
2. 每条经验自包含：现象 + 原因 + 解决 + 验证，他人可直接照做。
3. 报错信息保留原文片段，便于搜索。
4. 区分"本项目特有"与"通用环境"：通用问题可进一步沉淀到用户级知识。

# Work Progress

本文件按**倒序**记录每一轮工作（最新在上）。每轮条目包含：日期、标题、做了什么、关键结果、证据/提交、下一步。

> 日期格式 `YYYY-MM-DD`。以下为占位示例，实际项目替换。

## YYYY-MM-DD [标题] — 占位示例

- 做了什么：（描述本轮工作内容）
- 关键结果：（最重要的产出 / 数字 / 证据）
- 证据 / 提交：（提交号或证据路径）
- 下一步：（下一轮要做什么）

---

## 规则

1. 每轮结束**在顶部插入**新条目，保持倒序。
2. 同步更新 `agent_handoff/status_logs/CURRENT_STATUS.md`、`TASK_BOARD.md`、`CURRENT_RUN_HANDOFF.md`。
3. 关键数字必须指向 `project_docs/evidence/` 中的证据包或具名基线。

# 工作日志（LOGS）

> **总工作日志**：按时间**正序**持续追加（最新在底部），记录每次关键工作 / 决策 / 会话，便于回溯与查询。

## 与其它记录的分工

| 文件 | 定位 |
|------|------|
| `LOGS.md` | **完整事务日志**（本文档）：每条关键动作都记，正序累积 |
| `WORK_PROGRESS.md` | 每轮进展流水账（倒序，最新在上） |
| `status_logs/CURRENT_STATUS.md` | 当前一轮状态 |
| `reports/weekly/` | 周期总结 |

## 日志条目模板

```
### YYYY-MM-DD HH:MM [类型] 一句话简述

- 内容 / 决策 / 结果：
- 相关文件 / 提交：
- 关联：`WORK_PROGRESS.md`、`project_docs/evidence/...`
```

类型：`开发` / `实验` / `论文` / `评审` / `决策` / `修复` / `交接` / `其他`

## 查询方式

- 按日期：搜索 `YYYY-MM-DD`
- 按类型：搜索 `[类型]`
- 按关键词：搜索路径、报错、决策主题

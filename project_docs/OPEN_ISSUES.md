## 规则

1. 任何未解决的问题**发现即登记**，不管多久未解决都持续保留在本清单。
2. 每轮工作检查：未决问题是否有进展、是否可解决；有进展就更新"尝试过 / 下一步"。
3. **未决问题必须告知用户**：交付 / 汇报 / 交接时都要列出，不得因影响不利而隐瞒。
4. 交接文档（`CURRENT_RUN_HANDOFF.md`、`NEXT_AGENT_PROMPT.md`）必须列出全部未决问题。
5. 解决后移入"已解决"区，记录日期与解决方式，保留历史供查。

# versions — 冻结版本集合

> 存放冻结版本的完整工程快照。每个版本目录是**完整体**：含该版本的 `code/`（源码+脚本+测试）、`project/`（构建工程）、`experiments/`（实验），**零交叉引用**——不引用其他版本或项目级目录的任何文件。

## 版本目录结构

```text
versions/
|- v1/
|  |- README.md         # 版本说明（绑定基线、日期、变更摘要）
|  |- code/             # 该版本代码完整副本（源码+脚本+测试）
|  |- project/          # 该版本构建工程 / 配置
|  `- experiments/      # 该版本实验
`- v2/ ...
```

## 版本生命周期

1. 在根 `code/` 开发推进 → 阶段性完成 → 打基线（`project_docs/baselines/`）+ git tag。
2. **完整复制** `code/`、`project/`、`experiments/` 到 `versions/<基线ID>/`。
3. 复制后该版本自成一体：后续功能在 `code/` 继续推进，旧版本不受影响。
4. 论文（`paper/`）、数据（`data/`）、过程文档（`project_docs/`）为**项目级共享**，由基线与证据交叉表绑定版本，不随版本复制。

## 规则

- 版本目录一旦冻结**不可修改**；如需更新，复制出新版本目录。
- 禁止跨版本引用文件（含脚本）；需要即复制进本版本目录。
- 当前在 `code/` 推进的版本 = `BASELINE_INDEX.csv` 中 `status=active` 的基线。

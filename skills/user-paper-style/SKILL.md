# Paper Writing Style

与 `paper-writing-workflow` 配合使用。

## 语言与术语

- 中文稿优先，英文稿等中文稳定后再同步。
- 正文写成成熟论文，不写版本迭代、开发过程或防御性说明。
- 中文稿中优先使用中文术语；英文只保留必要专名、工具名、器件名、模块名、文件名和首次出现的标准缩写。
- 缩写首次出现写成"缩写（English Full Name）"，后文只用缩写。
- 术语以 `paper/GLOSSARY.md` 为准；新增术语先登记，再在正文使用。
- 图表只保留支撑论点的指标。段落中避免连续堆叠多个数字。

## 证据边界

- 每条数字必须标明口径：软件复现 / 策略复现 / 硬件 RTL 回放 / 工具报告 / 板级实测。
- 没有对应级别证据时不得升级声称。
- 有限窗口 / 有限样本的观察结论必须标注样本量与窗口大小，不得写成无限制保证。

## 图表规则

- 图内不生成标题、图号、图注、作者、水印。
- 源文件（draw.io）放 `paper/zh/figures/sources/`，定稿 PNG 放 `paper/zh/figures/final/`。
- LaTeX 只读取 `figures/final/`；未采用版本放 `candidates/`。
- 结构图要画真实部件关系（模块连线、数据流、控制信号）。
- 单栏图优先服务一个论点；不要把系统总览、模块细节、控制面、时序过程塞进同一张图。
- 图在单栏缩放后仍需能读出关键标签和主数据流。
- 定量折线图避免"工具默认图"观感：关键趋势用线宽、线型、marker 和端点 callout 强化；终点数值若承载论点应直接标在图中。
- 使用局部坐标轴放大时，必须在图内标出放大范围，并在图题或正文说明放大目的与解释边界。
